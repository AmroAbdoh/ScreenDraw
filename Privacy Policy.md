# Privacy Policy

**Last updated: September 17, 2026**

Desktop Draw is a Windows desktop application that lets users draw, annotate, highlight, and place shapes over content displayed on their screen.

## Information We Collect

Desktop Draw does not intentionally collect, require, or transmit personal information.

The application does not require an account and does not ask users to provide information such as their name, email address, password, or payment details.

## Input and Screen Access

While Desktop Draw is running, it may temporarily process mouse movement, mouse button events, and relevant keyboard events. This access is required to support drawing, annotation, click-through behavior, and application controls.

Desktop Draw does not record keystrokes, store mouse or keyboard activity, monitor the content of other applications, or transmit input data to the developer or any third party.

The application displays a transparent overlay over the screen. It does not capture, save, upload, or transmit the underlying screen content.

## Drawings and Annotations

Drawings, shapes, and typed annotations are processed locally on the user's device. They remain in the application's memory while the application is running and are removed when the application is closed or cleared by the user.

Desktop Draw does not automatically upload or store drawings, annotations, screenshots, or other user-created content on external servers.

Users may optionally export a drawing themselves to a file location they choose. Any exported file is controlled by the user and is not sent to the developer by Desktop Draw.

## Local Settings

Desktop Draw may store limited application settings locally for the user's convenience, such as the last selected drawing color and brush size.

These settings are stored on the user's device in the application's local settings folder. They do not contain personal information and are not collected, uploaded, or transmitted to the developer or any third party.

## Data Sharing

Desktop Draw does not sell, rent, share, or disclose user information to third parties.

## Third-Party Services

Desktop Draw does not use third-party analytics, advertising, authentication, tracking, cloud storage, or crash-reporting services.

The application may include open-source software libraries needed for features such as input handling, image export, system-tray integration, and application packaging. These libraries are used locally by the application and are not used to collect or transmit personal information.

## Internet Access

Desktop Draw does not require an internet connection for its core drawing and annotation functionality. The application does not make network requests or transmit data over the internet as part of its normal operation.

## Children's Privacy

Desktop Draw does not knowingly collect personal information from children or any other users.

## Data Security

Because Desktop Draw does not collect or transmit personal information, it does not maintain personal information on developer-controlled servers. Users are responsible for protecting any files they choose to export and store on their device.

## Changes to This Privacy Policy

This Privacy Policy may be updated if the application's functionality or data practices change. Any updated version will include a revised "Last updated" date.

## Contact

If you have questions about this Privacy Policy or Desktop Draw, please contact the developer through the project's official repository or support page.
